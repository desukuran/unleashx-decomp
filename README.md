# UnleashX, decompiled

Readable, buildable C++ source for **UnleashX v0.39.0528A (Build 584)**, the
classic replacement dashboard for the original Xbox, recovered from its
`Default.xbe` for preservation: so it can be read, fixed, modded and used as
the base for new dashboards.

> **This is not a byte-matching decompilation.** The source is rewritten
> by hand from the disassembly to *behave* like the original (quirks and
> bugs included, noted in comments), not to recompile into the same bytes.
> A build from it is a new `Default.xbe` that works like UnleashX; it is
> not the original file, and its code differs from it everywhere.

## Building

You need the **Xbox XDK** (built for 5933, the one UnleashX used). It is
Microsoft's and isn't included. Everything else is in this repository:
UnleashX's media and skins, the third-party libraries, and the disc tool.

```sh
# Linux or macOS (with Wine, make, a C compiler and Python 3)
make -f Makefile.xbox XDK=/path/to/xdk -j4 xiso
```

That gives `build/xbox/default.xbe` and a disc image, `build/xbox/UnleashX.iso`.
On Windows, open `vs2003/UnleashX.sln` in Visual Studio .NET 2003 with the
XDK installed, or use the same make command (MSYS2 or Git Bash) without
Wine. [BUILDING.md](BUILDING.md) has the details, running it in xemu or on
a console, and changing the media.

The source also builds on the host (`make test`, any modern g++) for its
tests: the XML, config, skin, FTP, HTTP and other portable parts.

## What works

`src/` holds the whole application; library code is linked as libraries.
Tried in xemu so far: the menus, the built-in skins and a zipped one from
the disc, the 3D background, the Control Panel, the file manager on the
hard disk, and DHCP networking. The rest (game saves, FTP, music, the
viewers, ...) is all there but hasn't been exercised on the rebuilt XBE
yet; reports welcome.

Not in the build:

* **USB storage**: UnleashX's FAT32 driver isn't rebuilt yet; USB drives
  don't show up.
* **WMV videos**: the WMV decoder wasn't part of the XDK. XMV videos play.
* **EEPROM decryption** is taken from the kernel, which has already done it
  (same results for the serial number, MAC, region and hard disk key).

## Layout

| Path | What |
|---|---|
| `src/` | UnleashX's code, by subsystem; every function carries its address in the original |
| `src/xdk/` | UnleashX's modified copy of the XDK sample framework (fonts, input, meshes, ...) |
| `xbox/` | Build support: adapters onto the third-party code, our ISO 9660 reader, EEPROM and DVD helpers |
| `thirdparty/` | libmad, unrar, zip_utils, ftpparse, extract-xiso ([licenses](thirdparty/README.md)) |
| `assets/` | UnleashX's media, built-in skins, font and title images; `disc/` is copied onto the disc |
| `vs2003/` | The Visual Studio .NET 2003 solution (generated by `tools/gen_vcproj.py`) |
| `docs/` | How UnleashX works: [skins](docs/SKIN_FORMAT.md), [menus](docs/MENU.md), [settings](docs/SETTINGS.md), [FTP](docs/FTP.md), [the main loop](docs/MAINLOOP.md), ... |
| `tests/` | Host tests |
| `symbols/`, `tools/` | The decompilation's naming database and tools ([docs/DECOMPILING.md](docs/DECOMPILING.md)) |
